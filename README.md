# Areej Flowers — نسخة مستقلة في ملف واحد

«مساحة للكلمات، والمعرفة، والأثر الجميل.»

مدونة شخصية كاملة لأريج خضر محمد النور — كاتبة وصانعة محتوى تعليمي وتثقيفي، طالبة في المستوى الثاني بكلية الطب، جامعة الشرق للعلوم والتكنولوجيا، كسلا، السودان — في ملف HTML واحد مكتفٍ بذاته، يعمل دون خادم.

## التشغيل

الطريقة الأبسط: افتح ملف `index.html` مباشرة في المتصفح (نقرة مزدوجة).

والأفضل، من سطر الأوامر داخل هذا المجلد:

```bash
python3 -m http.server 8000
```

ثم افتح: http://localhost:8000

> يحتاج الموقع إلى إنترنت فقط لتحميل خطوط Google (Cairo وPlayfair Display وInter). عند غياب الإنترنت يعمل الموقع بخطوط النظام الاحتياطية. كل شيء آخر — البيانات والصور والمحتوى — محلي بالكامل.

## ما بداخل الموقع

- **الصفحات:** الرئيسية، عن أريج، كتاباتي (بحث وفلترة بالتصنيفات و«تحميل المزيد» ووقت قراءة)، صفحة مقال (مقالات ذات صلة ومشاركة)، المحتوى التعليمي، يومياتي وأفكاري، تواصلي.
- **لغتان كاملتان:** عربي RTL افتراضياً وإنجليزي LTR، مع مبدّل في الترويسة وحفظ التفضيل.
- **وضعان:** فاتح وداكن بتصميم حقيقي لكل منهما، وسكربت في `<head>` يطبّق الوضع المحفوظ قبل الرسم لمنع الوميض.
- **استوديو تصميم:** خمسة أنظمة مختلفة فعلاً (أناقة اللافندر، البنفسج الملكي، زهرة ناعمة، أوركيد منتصف الليل، تحريري حديث) مع معاينة قبل التطبيق وإلغاء المعاينة واستعادة الافتراضي وتخصيص يدوي للألوان (بما فيها الأزرق والرمادي).
- **الهوية:** بنفسجي أساسي #79509B، وردي ثانوي #E7A8CB، أزرق مساعد #668FC2 للقسم التعليمي، رمادي مساعد #85858F للتوازن — بالترتيب دون عكس.
- **الصياغة:** كل العبارات الموجهة للزائر بصيغة المذكر («اكتشف كتاباتي»، «تعرف على أريج»، «اقرأ المزيد»، «تصفح المنشورات»).

## لوحة التحكم

افتح `#/admin` في المتصفح (أو رابط «لوحة التحكم» في الترويسة).

- **عند أول استخدام:** أنشئ رمز دخول PIN (6 أحرف على الأقل). يُحفظ تجزئة SHA-256 مع ملح فقط — لا يوجد رمز جاهز أو افتراضي. احفظ الرمز جيداً؛ لا توجد طريقة لاستعادته من الملف نفسه (يمكن مسح بيانات المتصفح وإعادة الإنشاء، لكن ذلك يحذف كل المحتوى).
- **الأقسام:** نظرة عامة بإحصائيات حقيقية، إدارة المنشورات بمحرر نصوص غني (عناوين، عريض/مائل، قوائم، اقتباس، روابط، صور، محاذاة)، إدارة التصنيفات مع تحذير قبل حذف المستخدمة، تحرير السيرة كاملة، مكتبة وسائط (رفع صور حتى 4MB)، الهوية والعلامة (شعار وصورة شخصية كأصلين منفصلين مع اختيار ما يظهر في الترويسة، وأيقونة الموقع)، إعدادات الموقع والروابط الاجتماعية، الرسائل الواردة، إعدادات SEO (مع تنزيل sitemap.xml وrobots.txt مولّدين من المحتوى الحقيقي)، الحساب والأمان (تغيير الرمز، حذف المحتوى النموذجي، نسخة احتياطية JSON).

## نموذج التواصل والرسائل

- النموذج ثلاثة حقول فقط: **الاسم والموضوع والرسالة** — كلها إلزامية، ولا يوجد حقل بريد إلكتروني نهائياً.
- الرسائل تُحفظ مباشرة في قاعدة البيانات وتظهر في «الرسائل الواردة» مرتبة من الأحدث، مع شارة جديدة/مقروءة وعدّاد غير المقروءة، وفتح وقراءة كاملة، وتحديد كمقروءة/غير مقروءة، وحذف بعد تأكيد.
- الحماية: تحقق من المدخلات، وحقل Honeypot مخفي ضد البوتات، وحدّ 5 رسائل كل 10 دقائق.
- **لا تُرسل الرسائل إلى أي بريد إلكتروني، ولا تظهر للزوار أبداً.**

## قاعدة البيانات

قاعدة IndexedDB حقيقية ودائمة باسم `areej-flowers` (مخازن: posts, categories, media, messages, settings, profile, auth). عند أول تشغيل تُزرع البيانات الحقيقية فقط (الاسم والجامعة والمدينة والفلسفة) + 3 تصنيفات + 3 مقالات موسومة بوضوح «محتوى نموذجي»، مع زر لحذفها كلها من لوحة التحكم. الإحصائيات كلها من العدّادات الحقيقية — لا أرقام وهمية.

## النشر

### GitHub Pages

1. أنشئ مستودعاً جديداً وارفع `index.html` (وهذا الملف) إليه.
2. من Settings ← Pages ← اختر الفرع `main` والمجلد `/ (root)`.
3. لا يوجد أي أمر بناء — الموقع ثابت بالكامل.

### Render (Static Site)

1. أنشئ Static Site واربطه بالمستودع.
2. Build Command: اتركه فارغاً.
3. Publish Directory: `.` (الجذر).

## قيد مهم — اقرأه بصراحة

**البيانات تعيش في متصفح الجهاز (IndexedDB).** هذا يعني:

- المقالات والصور والرسائل والإعدادات التي تنشئها أريج على جهازها تظهر على جهازها فقط؛ زائر يفتح الموقع من جهاز آخر يرى نسخة ببياناته الخاصة (أو البيانات النموذجية إن لم ينشئ شيئاً).
- هذه النسخة مناسبة للاستخدام الشخصي، والعرض، والتجربة، والاحتفاظ بنسخة محلية كاملة من الموقع.
- **للنشر العام المشترك** — حيث تنشر أريج مقالاً فيراه كل الزوار، وتصلها رسائلهم جميعاً — يحتاج الموقع إلى خادم وقاعدة بيانات مشتركة (مثل Supabase مع استضافة). هذا الملف الواحد لا يمكنه توفير ذلك بطبيعته، وأي ادعاء بخلاف ذلك غير صحيح.

للتأكد من سلامة الملف تقنياً: كل سكربتات JavaScript المضمّنة فيه اجتازت فحص الصياغة `node --check` دون أخطاء، والملف يبدأ بـ DOCTYPE وينتهي بـ `</html>`، ولا يشير لأي ملف خارجي عدا خطوط Google.
